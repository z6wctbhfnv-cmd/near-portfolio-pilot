# Ключи и аккаунты: что делает Александр

Это то, что Claude сделать не может. Он не регистрируется на сервисах, не входит в аккаунты, не принимает условия использования и не переводит деньги.

Все ключи кладём в `~/near-portfolio-pilot/.env`. В чат их не вставляем. `.env` не попадает в git: он указан в `.gitignore`.

```bash
cp ~/near-portfolio-pilot/.env.example ~/near-portfolio-pilot/.env && open -e ~/near-portfolio-pilot/.env
```

Порядок важен: шаги 2, 4 и 5 требуют NEAR-кошелёк из шага 1.

## 1. NEAR-аккаунт (≈10 минут)

Этот аккаунт решает три задачи:

- получает приз (в заявке нужен именной `имя.near` или 64-символьный неявный аккаунт);
- владеет демо-агентом в Agent API;
- служит для входа в OutLayer.

**Вариант А — Meteor Wallet (рекомендую):**

1. Открой https://wallet.meteorwallet.app в Chrome или поставь расширение Meteor Wallet.
2. Нажми «Create new wallet».
3. Выбери именной аккаунт, например `nppilot.near`. Если именной требует оплаты, начни с неявного (64 символа) и создай именной позже.
4. **Запиши сид-фразу на бумагу.** Не фотографируй и не храни в облаке. Ключ владельца агента восстановить нельзя: потерял — агент заблокирован навсегда.
5. Пополни аккаунт на 1–2 NEAR (≈$5–10): купи NEAR на бирже и выведи на адрес аккаунта. Это нужно на газ и хранение данных.

**Вариант Б — near.com:** войди через passkey и найди ID аккаунта в настройках. Если ID там не показан, используй вариант А.

В `.env`:

```
NEAR_ACCOUNT_ID=nppilot.near
```

## 2. Ключ Agent API (≈5 минут)

1. Открой https://partners.demo.agentsonintents.com/dashboard.
2. Войди кошельком из шага 1.
3. Создай API key. Ключ живёт 365 дней, его можно отозвать.
4. Скопируй ключ сразу: обычно его показывают один раз.

В `.env`:

```
NEAR_INTENTS_AGENT_API_KEY=<ключ>
NEAR_INTENTS_AGENT_API_URL=https://api.demo.agentsonintents.com
```

Важно: API работает только в mainnet и находится в бете. Его оператор (NEAR Technologies Limited) прямо предупреждает, что деньги можно потерять. Когда будем создавать агента, ты увидишь условия владельца, условия OutLayer и уведомление о рисках. Прочитай их и прими сам.

## 3. Партнёрский ключ NEAR Intents (≈5 минут)

Без ключа 1Click берёт 0,2% с каждого обмена. С ключом комиссия ниже, и ключ нужен для стабильной работы демо для судей.

1. Открой https://partners.near-intents.org.
2. Войди: кошелёк или почта, как предложит сайт.
3. Создай API-ключ (JWT).

В `.env`:

```
NEAR_INTENTS_PARTNER_KEY=<ключ>
```

## 4. NEAR AI Cloud (≈5 минут)

Нужен для двух задач: перевести правила со слов в политику и делать еженедельную ревизию. Модель работает в TEE.

1. Бесплатные $10: вступи в NEAR Builders на https://nearbuilders.org/join и следуй их инструкции по кредитам.
2. Открой https://cloud.near.ai и войди.
3. Developer Settings → Create New API Secret.

В `.env`:

```
NEARAI_API_KEY=<ключ>
```

---

## 5. OutLayer (≈10 минут)

Там будут запускаться стратегии в TEE с доказательством каждого запуска.

1. Открой https://app.outlayer.ai.
2. Нажми Connect и войди NEAR-кошельком из шага 1.
3. В разделе Payments → Payment keys создай ключ.
4. Пополни небольшой суммой, если сайт попросит. Цены смотри в Pricing & Limits.

В `.env`:

```
OUTLAYER_PAYMENT_KEY=<ключ>
```

## 6. Деньги на демо-агента (около 12 ноября)

Когда Claude подготовит создание агента, порядок такой:

1. Ты подписываешь создание агента в своём кошельке и принимаешь условия.
2. Сервис выдаёт адрес депозита.
3. Отправляешь на него $10–20 в USDC из любой сети (Base, Arbitrum, Solana и других).

Больше класть не нужно.

## 7. GitHub-токен (по желанию, ≈3 минуты)

В `~/.zshrc` (строка 15) задан устаревший `GITHUB_TOKEN`, из-за которого `gh` не работает. Отключи строку сам: команда делает резервную копию и закомментирует её.

```bash
cp ~/.zshrc ~/.zshrc.bak && sed -i '' 's/^export GITHUB_TOKEN=/# export GITHUB_TOKEN=/' ~/.zshrc && exec zsh
```

После этого `gh` будет пользоваться твоим входом.

В `~/.claude.json` лежит, вероятно, тот же старый токен для GitHub-сервера Claude. Если хочешь, чтобы этот сервер работал:

1. Открой https://github.com/settings/tokens.
2. Выбери Generate new token (classic) с правом `repo`, срок — 30 дней.
3. Вставь новый токен в `~/.claude.json` вместо старого и перезапусти Claude.
